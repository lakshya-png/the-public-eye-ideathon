# PublicEye - Civic Issue Reporting Platform

PublicEye is a civic issue reporting platform designed to help citizens report public problems such as potholes, garbage accumulation, broken streetlights, water leakage, and other local issues. The platform allows users to submit complaints, track their status, and enables administrators to manage and resolve reported issues efficiently.

## Features

- User-friendly complaint submission system
- Complaint tracking using a unique complaint ID
- Category-based issue reporting
- Photo upload support for evidence
- Anonymous complaint option
- Admin dashboard for complaint management
- Status updates for submitted complaints
- Responsive interface for desktop and mobile devices

## Main Functionalities

### Citizen Features
- Submit civic complaints
- Upload issue images
- Select complaint category
- Track complaint status using complaint ID
- Report anonymously if required

### Admin Features
- View all complaints
- Update complaint status
- Manage complaint records
- Monitor pending and resolved issues
